The Goobster installer has been unpacked

If someone is logged in at this Mac, the install wizard opens in the browser at http://127.0.0.1:3400/manager/. If it does not, or the window was closed, run this in Terminal:

/opt/goobster/stage/@VERSION@/runtime/bin/node /opt/goobster/stage/@VERSION@/app/apps/manager/bootstrap/darwin.js --payload /opt/goobster/stage/@VERSION@ --per-user --open-browser

When an answers file named /etc/goobster-answers.json was present, the machine-wide install was done without a wizard; its result is in /var/log/goobster-install.log.

The unpacked copy under /opt/goobster/stage can be deleted once Goobster is installed.
