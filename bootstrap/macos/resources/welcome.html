Goobster @VERSION@ for macOS (@ARCH@)

@BUILD_NOTICE_HTML@

This installer puts the Goobster release on this Mac and starts the Goobster install wizard in your web browser. Nothing is configured until you finish the wizard.

  • The wizard runs as you, on 127.0.0.1:3400 only. It is never reachable from the network.
  • By default Goobster is installed for your own account and runs while you are logged in (a launch agent).
  • An administrator who wants the always-on, machine-wide service (a launch daemon that runs as the hidden _goobster account) provides an answers file at /etc/goobster-answers.json before running this installer; see the documentation.

Requires macOS 13 Ventura or newer.
