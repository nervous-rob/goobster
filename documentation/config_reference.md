# Configuration reference

Generated by `node scripts/generate-config-reference.js` from `packages/core/config/fieldCatalog.js`; do not edit it by hand (`npm run docs:check` fails when it is stale).
How the manager reads, shows and changes these settings is in `documentation/manager_configuration.md`; the general setup guide is `documentation/configuration.md`.

Precedence, unless a row says otherwise: environment variable, then `config.json`, then the default. A secret is never shown: the manager reports only whether it is set, where it comes from and its last four characters. "Restart" means the setting is read when a process starts; "hot" means it is read per request.

## Provider connection checks

A check runs only when an operator asks for it (`POST /manager/api/config/probe`); nothing runs on a status or page load. Each check authenticates and reads one cheap, unbilled resource; none generates anything.

| Target | What it does | Credential goes to |
| --- | --- | --- |
| `openai` | Lists the models your OpenAI key can see (GET /v1/models). Nothing is generated and nothing is billed. | `api.openai.com` |
| `anthropic` | Lists the models your Anthropic key can see (GET /v1/models). Nothing is generated and nothing is billed. | `api.anthropic.com` |
| `gemini` | Lists the models your Gemini key can see (GET /v1beta/models). Nothing is generated and nothing is billed. | `generativelanguage.googleapis.com` |
| `perplexity` | Lists your own queued asynchronous requests (GET /async/chat/completions): Perplexity has no model-list endpoint, and this authenticated read starts no search and is not billed. | `api.perplexity.ai` |
| `elevenlabs` | Reads your ElevenLabs account (GET /v1/user). No audio is generated and no characters are used. | `api.elevenlabs.io` |
| `github` | Reads the account the GitHub token belongs to (GET /user). Nothing is created or changed. | `api.github.com` |
| `cursor` | Lists the models your Cursor key can launch agents with (GET /v1/models), the same call the launcher makes. No agent is started. | `api.cursor.com` |
| `ollama` | Asks your Ollama server which models it has installed (GET /api/tags). No credential is sent and nothing is generated. | nowhere (no credential is sent) |
| `mail` | SMTP: opens a connection to your mail server and sends EHLO, then quits; no login, no message. Resend: lists your sending domains (GET /domains) with the key; no message is sent. | nowhere (no credential is sent) |
